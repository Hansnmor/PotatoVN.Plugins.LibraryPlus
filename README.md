# PotatoVN.Plugins.LibraryPlus

为 [PotatoVN](https://potatovn.net) 提供**游戏库增强**功能的插件：更多排序条件、过滤与统计数据，全部在独立页面中完成，不影响原生页面。

## 功能

侧边栏新增「游戏库增强」入口，进入一个**与原生游戏库页功能一致**的独立页面：

- **布局一致**：使用与原生页面相同的游戏卡片（封面尺寸、名称显示、游玩状态角标等），网格随窗口宽度自适应排列
- **交互一致**：
  - 单击游戏卡片 → 进入游戏详情页（带与原生一致的封面过渡动画）
  - 右键卡片 → 游玩状态修改 / 编辑游戏信息 / 下载游戏信息 / 在文件管理器中打开 / 从游戏库删除
- **排序更多**（本页唯一差异）：
  - 主排序键 + 次排序键多级排序，各自可选升序/降序
  - 排序条件：预计时长 / 游玩时间 / 游玩次数 / 我的评分 / 默认顺序
  - 未填写预计时长、未游玩（0 分钟 / 0 次）、未评分（0 分）的游戏无论升序降序都排在最后
  - 排序设置持久化，返回页面/重启应用后保持
- **状态筛选（包含式）**：工具栏「筛选」菜单按游玩状态筛选，含快捷预设：
  - **全部**（默认，不过滤）/ **待玩**（未标记+游玩中+想玩）/ **自定义**（勾选=只显示这些状态）
  - 自定义可多选组合（如只显示"游玩中+想玩"），勾选后关闭菜单统一生效（CheckBox 可一次勾多个）；勾选状态时自动进入自定义模式；切到「全部/待玩」预设会清空自定义选择
  - 与时长区间筛选为 AND 关系（如：待玩 + <10h = 找未玩且几小时能通完的）
  - 筛选设置持久化，返回页面/重启应用后保持
- **时长区间筛选**：<10h（短篇小品） / 10-20h（单线） / 20-40h（中等） / >40h（长篇） / 时长未知，与「状态筛选」为 AND 关系；时长未知的游戏单独归入「时长未知」档（不在四个时长区间内）
- **时长统计条**（跟随当前可见列表）：待玩总时长 / 完成度（已玩数/总数） / 时长未知数
- **内容分类筛选与统计**：分类按钮组（全部/萌作/剧情作/拔作/同人作/其他）可筛选，与时长区间、状态筛选 AND 联动（如 &lt;10h 的拔作）；统计条下方一行显示当前可见列表的分类分布，基于本地标签与引擎分类（优先级：同人作（RPG Maker 等引擎/同人标签） &gt; 拔作 &gt; 剧情作 &gt; 萌作 &gt; 其他，无信号归「其他」）
- **数量统计**：左上角显示「共 xx 款游戏」，跟随过滤实时变化

**完全独立**：本页的排序与操作只作用于插件页面，不影响 PotatoVN 自带的【游戏】页面及其排序。

## 使用方法

1. 在 PotatoVN 的插件管理页安装本插件并启用。
2. 侧边栏点击「游戏库增强」进入独立页面。
3. 点击工具栏「排序」选择排序条件与方向；用「筛选」菜单按状态筛选（含待玩预设），或选择时长区间；统计条跟随可见列表实时更新。

## 实现说明

- 排序页面是插件自己的 WinUI `Page`（`Controls/SortPage`），通过侧边栏按钮进入（`IPotatoVnApi.NavigateTo` + `RegisterSidebarButton`）。
- 列表使用 `AdvancedCollectionView` + 自定义 `IComparer` 实现排序，不触碰宿主 `HomeViewModel` 的任何状态。
- 点击进详情 / 打开设置页通过 `IPotatoVnApi.NavigateTo(PageEnum.GalgamePage / GalgameSettingPage)` 完成；
  保存、删除、搜刮信息等操作通过 `HostServices` 反射调用宿主 `GalgameCollectionService` 的公开方法。
- 侧边栏选中指示器（蓝色小条）跟随：宿主只自动匹配内置导航项，插件按钮需通过 `SidebarSelectionHelper`
  反射设置 `NavigationView.SelectedItem`——进详情时移到「游戏」项，返回插件页时移回「游戏库增强」。
- 状态筛选、区间、排序等页面状态持久化在插件数据（`PluginData`）中；插件页面由宿主 `PluginHostPage` 每次重新创建，因此页面状态均通过插件数据保存/恢复。
- 预计时长解析与统计统一走 `Helper/ExpectedPlayTimeHelper`（支持 VNDB 格式 `1h30m`/`45m` 及 `very short` 等类别映射），排序比较器、区间筛选、统计三处共用。

## 开发

- `PotatoVN.App.PluginBase`：插件本体
- `PotatoVN`：PotatoVN 主项目（git submodule，含 WinApp.Base 应用公开库）
- 开发文档见 `doc/` 目录

构建插件包（Release）：`dotnet build PotatoVN.App.PluginBase/PotatoVN.App.PluginBase.csproj -c Release`，产物位于 `artifacts/plugin.pvnplugin.zip`。
